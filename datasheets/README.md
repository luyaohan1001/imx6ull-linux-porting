# Datasheets

Reference documents for the i.MX6ULL (正点原子 / Alientek eMMC) board:
SoC reference manual and datasheet, board schematics, and datasheets for
on-board parts (PMIC, DDR, eMMC, Ethernet PHY, LCD, sensors, ...).

## Layout

Every document gets its own subfolder, named after the document number
or part (e.g. `IMX6ULLCEC/`), holding:

- the file itself (e.g. `IMX6ULLCEC.pdf`), and
- a `README.md` with the title, revision/date, the original download
  link, the download date and the file's SHA-256.
